# Inventory Management System — Frontend

React + Vite dashboard for managing inventory.

## Run
1. `npm install`
2. Optional: copy `.env.example` to `.env`.
3. `npm run dev`

The frontend defaults to `http://localhost:3000/api` when Vite API variables are not set.

Features:
- JWT login/register
- Inventory dashboard and summary cards
- Search by product, SKU, or category
- Add, edit, and delete products
- Low-stock indicators
- Supplier, SKU, quantity, reorder level, and unit-price tracking
